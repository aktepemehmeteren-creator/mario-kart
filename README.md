# Mario Kart PSP - Fan Project

PSP homebrew fan-game project inspired by kart-racing games. No Nintendo game assets are included.

## GitHub Actions ile EBOOT.PBP

1. Bu klasördeki dosyaları yeni bir GitHub repository'sine yükle.
2. GitHub'da **Actions** sekmesine gir.
3. **Build Mario Kart PSP** workflow'unu seç.
4. **Run workflow** ile çalıştır veya `main` branch'e push et.
5. İşlem bitince **Artifacts** altında `MarioKartPSP-EBOOT-PBP` dosyasını indir.

## PSP'ye kurulum

İndirilen `EBOOT.PBP` dosyasını Memory Stick'e şu şekilde koy:

`PSP/GAME/MARIOKART/EBOOT.PBP`

Sonra PSP'de **Game > Memory Stick** içinden oyunu başlat.
